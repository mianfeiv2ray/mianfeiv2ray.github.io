  1. 打开V2rayNG：安装后首次打开，应用可能会请求创建VPN配置的权限，请允许（这是其实现全局代理的基础）。

  3. 填写订阅信息：
    • 备注：可自定义名称，如“我的付费服务”。
    • 地址（URL）：粘贴你从服务商处获取的完整订阅链接。

第三步：选择节点并连接

第四步：进阶设置与优化

  • 路由设置：点击右上角三个点 -> “设置” -> “路由”。可设置“绕过局域网和大陆”（推荐），实现国内网站直连、国外网站代理，节省流量提升速度。
  • 分应用代理：在“设置” -> “分应用代理”中，可以指定哪些App走代理，哪些直连。
  • 传输协议：对于高级用户，如果某个节点连接不稳定，可以点击节点进入“编辑配置”，尝试修改“传输协议”为WebSocket或mKCP等（需服务端支持）。

Sing-box 是否比 Clash 更省资源？

Sing-box 的多出口策略有什么作用？
多出口策略允许不同流量通过不同节点访问。例如视频流量通过高速节点，普通网页使用备用节点，实现资源优化与智能分流，提高网络使用体验。
QuantumultX 支持按端口进行流量分流吗？
支持。用户可以根据端口号将不同应用流量分流到指定节点。例如游戏走低延迟节点，浏览网页走普通节点，实现精准流量管理和优化网络访问速度。
Clash 的 Rule Provider 有什么作用？
Rule Provider 是 Clash 的规则分发机制。用户可以订阅不同的规则集，比如广告拦截、社交媒体、流媒体等，实现按需加载。它让配置文件更加简洁、动态更新，并支持多源规则管理。
VMess TLS 与 WebSocket 组合有哪些优势？
TLS + WebSocket 可将 VMess 流量伪装为 HTTPS，隐藏真实通信特征。结合策略组使用，可增强抗封锁能力，提高节点稳定性和访问速度，特别适合视频和游戏场景。
Matsuri 节点延迟排序可以自动切换吗？
Matsuri 会定期测速节点延迟，结合策略组，可自动选择延迟最低的节点处理流量。这样用户无需手动切换节点，就能保持访问速度和稳定性，优化网络体验。
SSR 的混淆插件如何增强隐蔽性？
混淆插件可模拟正常协议特征，如 HTTP 或 TLS 流量，使 SSR 流量难以被检测。合理选择混淆方式和协议，可提升在高封锁环境下的长期稳定性和安全性。
Surfboard 支持哪些类型的节点导入？
